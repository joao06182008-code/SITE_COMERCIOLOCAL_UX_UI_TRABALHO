# 🚀 Nome do Projeto

> Melhor Produto Local

## 💻 Sobre o Projeto
O site localiza os fornecedores mais baratos e pertos da loja do comerciante, calculando o tempo de entrega 
e os preços do produto.

## 🛠️ Tecnologias Utilizadas
Ultilizamos HTML e CSS para a parte estética do site
e JavaScript para o funcionamento

## 🚀 Como ultilizar o Site
Simples, tera a barra de pesquisa você coloca o nome do produto que deseja e ele ira buscar
o produto mais acessivel ao comerciante.
